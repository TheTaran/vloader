Use ../AGENTS.md, ../Security.md and ../securityskills.md. Prioritize authentication bypass, token exposure, SSRF, path traversal, DOM injection and resource exhaustion. No live external integrations have been security-certified. Record future findings with severity, evidence, remediation and verification.
