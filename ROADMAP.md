# Roadmap

## Initial implementation
Go/Docker GUI, local and OIDC login, Emby metadata mirror, images, browser downloads, read-only NFS/SMB deployment options and security/testing documentation.

## Deployment acceptance
Connect the intended Emby server, OIDC provider and chosen share; validate original media downloads. Create/link GitHub repository and upload reviewed bootstrap.

## Optional future work
Per-user roles, offline image cache, scheduled synchronization and server-side download queue require separate scope decisions.
